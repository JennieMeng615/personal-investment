# Personal Investment Dashboard（个人投资看板）

一个**完全在浏览器本地运行**的个人投资看板网页。不需要安装任何软件，不需要注册账号，用 iPhone 的 Safari 就能打开使用。

> ⚠️ **重要说明**
> - 本工具**不连接**任何银行、券商或行情接口，**不会**执行任何交易。
> - 页面里的价格**不是实时行情**：初始的 VOO、VTI 和现金都是**虚构的示例数据**，价格是编造的；之后的价格需要你自己从券商 App 查看后手动填写。
> - 带有黄色「示例」标签的数据仍是虚构数据；你编辑过的记录会自动去掉这个标签。
> - 数据只保存在你当前使用的这台设备、这个浏览器里，不会上传到任何地方。
> - 本工具仅用于个人记录和学习，不构成投资建议。

## 功能

| 功能 | 说明 |
| --- | --- |
| 资产概览 | 总资产、现金、股票和 ETF 市值、总盈亏、收益率 |
| 持仓表格 | 股票代码、名称、持有数量、平均买入价、当前价格、市值、盈亏金额、收益率，以及合计行 |
| 资产配置图 | 环形图，显示每个持仓和现金占总资产的比例 |
| 投资表现图 | 条形图，对比每个持仓的买入成本和当前市值 |
| 添加 / 编辑 / 删除 | 修改后所有指标、表格、图表自动重新计算 |
| 本地保存 | 自动保存在浏览器里，刷新或关闭页面后数据仍在 |
| 深色模式 | 跟随 iPhone 系统的浅色 / 深色设置 |

## 计算方法

| 指标 | 公式 |
| --- | --- |
| 成本 | 持有数量 × 平均买入价 |
| 市值 | 持有数量 × 当前价格 |
| 盈亏金额 | 市值 − 成本 |
| 收益率 | 盈亏金额 ÷ 成本（成本为 0 时显示「—」） |
| 股票和 ETF 市值 | 所有持仓市值之和 |
| 总资产 | 现金 + 股票和 ETF 市值 |
| 总盈亏 | 所有持仓盈亏之和（现金不计盈亏） |
| 收益率（总） | 总盈亏 ÷ 所有持仓总成本 |
| 配置占比 | 某一项金额 ÷ 总资产 |

**示例数据核对**（可以用计算器验证）：

- VOO：12 股 × $480 = 市值 $5,760；成本 12 × $420 = $5,040；盈亏 +$720（+14.29%）
- VTI：25 股 × $255 = 市值 $6,375；成本 25 × $230 = $5,750；盈亏 +$625（+10.87%）
- 现金：$8,000
- 总资产 = 8,000 + 5,760 + 6,375 = **$20,135**
- 总盈亏 = 720 + 625 = **+$1,345**；收益率 = 1,345 ÷ 10,790 = **+12.47%**

颜色约定：**绿色表示盈利，红色表示亏损**（美股习惯），数字前也会显示 + / − 号。

## 如何使用（iPhone）

### 第一步：让网页可以在手机上打开（只需做一次）

这个项目是纯网页文件，可以用 GitHub 免费的 **GitHub Pages** 功能发布成一个网址：

1. 在 iPhone 的 Safari 打开 `https://github.com/jenniemeng615/personal-investment` 并登录。
2. 如果这些代码还在 `claude/personal-investment-dashboard-u0z66h` 分支上，先把它合并到 `main`：
   点上方的 **Pull requests** → 找到对应的 PR（没有的话点 **New pull request**，选择这个分支）→ **Merge pull request** → **Confirm merge**。
3. 点仓库上方的 **Settings**（如果看不到，把页面往右滑，或点「…」）。
4. 左侧菜单（手机上可能在页面下方）找到 **Pages**。
5. 在 **Build and deployment** 中，**Source** 选 **Deploy from a branch**；**Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**。
6. 等 1～3 分钟，刷新这个页面，顶部会出现网址，类似：
   `https://jenniemeng615.github.io/personal-investment/`
7. 用 Safari 打开这个网址即可使用。

> 提示：如果你的仓库是**私有（Private）**的，免费账户可能无法使用 GitHub Pages。可以在 Settings → General 最下方把仓库改为 Public（注意：代码会公开，但你在网页里录入的持仓数据**不会**公开，它们只存在你自己的手机浏览器里）。

### 第二步：添加到主屏幕（可选）

在 Safari 中打开网址后，点底部的「分享」按钮 → **添加到主屏幕**，以后就能像 App 一样从桌面打开。

> 注意：从主屏幕图标打开和从 Safari 打开，数据是**分开保存**的。请固定用其中一种方式。

### 日常使用

- **修改现金**：点「现金」卡片。
- **添加持仓**：点「＋ 添加持仓」，填写代码、类型、数量、平均买入价和当前价格。填写时下方会实时预览市值和盈亏。
- **编辑持仓**：在表格最右边点「编辑」（手机上需要把表格向左滑动）。
- **删除持仓**：进入编辑后点「删除此持仓」，再点一次「确认删除」。
- **更新价格**：本工具不会自动更新价格。请定期从券商 App 查看价格，然后编辑对应持仓的「当前价格」。
- **恢复示例数据**：页面底部按钮，需要连点两次确认。**这会清除你录入的所有数据。**

### 数据保存注意事项

- 数据保存在浏览器的本地存储（localStorage）中。
- 以下情况会导致数据丢失：清除 Safari 的「历史记录与网站数据」、使用无痕浏览、换手机或换浏览器。
- 第一版暂不支持备份导出，建议重要数据另外记录。

## 如何测试计算是否正确

### 方法一：在手机上测试（最简单）

打开看板页面，滑到最下方，点 **「运行计算测试」**。页面会自动检查 19 项计算和校验规则，全部通过会显示「全部 19 项测试通过 ✓」，有问题会用红色列出具体哪一项不对。

也可以直接打开：`你的网址/tests.html`

### 方法二：在电脑上测试

需要安装 [Node.js](https://nodejs.org/)（18 或以上版本），然后在项目文件夹里运行：

```bash
npm test
```

不需要安装任何其他依赖。

### 方法三：手动核对

用计算器按上面「示例数据核对」一节的步骤算一遍，和页面显示的数字对比。

## 文件结构

```
index.html            看板主页面
tests.html            浏览器里运行的测试页面
css/style.css         样式（颜色、布局、手机适配、深色模式）
js/calc.js            所有计算和数据校验逻辑（纯函数，方便测试）
js/charts.js          资产配置图、投资表现图
js/app.js             页面交互：保存/读取数据、添加/编辑/删除
tests/calc-cases.js   测试用例（电脑和浏览器共用）
tests/run-tests.js    电脑上运行测试的入口
package.json          只用于 `npm test` 命令，无任何依赖
```

## 隐私与安全

- 不包含任何密钥、账号或密码。
- 不发起任何网络请求获取数据（唯一的外部资源是 Google Fonts 字体，加载失败时会自动使用系统字体）。
- 所有用户输入都以纯文本显示，不会被当作代码执行。
